# Digital License - VicRoads Inspired Digital Wallet

A high-fidelity Flutter digital wallet and transport management app inspired by VicRoads/Service Victoria.

## Architecture

- **Clean Architecture** with separation of concerns
- **BLoC** state management
- **GetIt** dependency injection
- **Hive** local caching
- **flutter_secure_storage** for token management

## Features

- Digital Driver License with animated card flip
- QR Code generation (30-second refresh)
- Vehicle registration management
- Privacy mode toggle
- Offline-first approach
- Government-style UI

## Setup

```bash
flutter pub get
flutter run
```
