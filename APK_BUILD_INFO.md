# Build APK Instructions

This file documents how the APK was built.

## Build Command Used:
```bash
flutter build apk --release
```

## Output Location:
```
build/app/outputs/flutter-apk/app-release.apk
```

## APK Details:
- **Size:** ~50MB (typical for Flutter apps)
- **Min API Level:** 21 (Android 6.0+)
- **Supported ABIs:** arm64-v8a, armeabi-v7a

## Installation Steps:

1. Download `app-release.apk`
2. Transfer to your Android phone
3. Open Files app on phone
4. Tap the APK file
5. Tap "Install"
6. Launch the app
