# Digital License APK - Quick Start

## 📱 Installation (30 seconds)

### **Step 1: Download**
- Download `app-release.apk` from Releases
- Or scan QR code to get download link

### **Step 2: Install on Phone**
1. Open file manager on your Android phone
2. Find the APK file
3. Tap it → "Install"
4. Wait for installation ✅

### **Step 3: Launch**
- Find "Digital License" app on your home screen
- Tap to open

## 🆘 Troubleshooting

### "Installation blocked"
- Go to Settings → Security → Unknown sources → Allow
- Then try installing again

### "App crashes on startup"
- Uninstall and reinstall
- Clear cache: Settings → Apps → Digital License → Clear Cache

### "Login fails"
- Check credentials: `521vic125` / `demo123`
- Check internet connection
